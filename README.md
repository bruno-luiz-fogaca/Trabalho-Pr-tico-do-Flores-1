# Objetivo
Desenvolver uma página web simples utilizando HTML puro, com foco na aplicação correta das principais tags e estruturas do HTML5, consolidando os conhecimentos adquiridos na disciplina.

# Descrição do Trabalho
O tema escolhido pelo grupo foi **"Viagem dos Sonhos"**, apresentando o destino **Madrid**, capital da Espanha, com seus pontos turísticos, dicas de viagem, curiosidades, custos estimados e um formulário para planejamento da viagem.

# Requisitos Técnicos Atendidos
- [x] Título principal e subtítulos** — uso das tags `<h1>` a `<h3>` (mais de 3 níveis)
- [x] Parágrafos de texto com a tag `<p>`
- [x] Links com a tag `<a>`, incluindo pelo menos um link externo (ex.: site oficial de Madrid, Museu do Prado)
- [x] Imagens com a tag `<img>`, todas com o atributo `alt`
- [x] Listas
- [x] Lista ordenada (`<ol>`) — Dicas de viagem
- [x] Lista não ordenada (`<ul>`) — Pontos turísticos e curiosidades
- [x] Tabelas com a tag `<table>`, contendo `<thead>`, `<tbody>` e `<tfoot>`, com mais de 2 colunas e 3 linhas — Custos estimados da viagem
- [x] Formulário com a tag `<form>`, contendo: Campo de texto (nome), Campo de e-mailCampo de seleção/dropdown (tipo de viagem), Botão de envio
- [x] Divisões de conteúdo usando a tag `<div>` para estruturar visualmente a página
- [x] Comentários HTML (`<!-- -->`) explicando as principais seções do código
